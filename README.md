# 📺 NigerToday TV - Subscription Management Dashboard

A modern, responsive, and feature-rich **Subscription Management Dashboard** built for **NigerToday TV** business owners to track active subscribers, monitor expiring plans, manage renewals, and configure account settings seamlessly.

---

## 🚀 Tech Stack

* **Frontend:** React, React Router DOM
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **UI Design:** Figma Reference Based Clean Layout

---

## ✨ Key Features

* **🔐 Secure Login:** Authentication screen for business owners.
* **📊 Interactive Dashboard:** Quick snapshot of total customers, active subscriptions, expiring soon, and recently expired lists with **Review Now** alerts.
* **👥 Customer Management:** Comprehensive list of customers with search, phone numbers, email, and detailed profile views.
* **➕ Add Customer:** Seamless form to register new customers with automatic plan calculation and subscription summaries.
* **⏰ Expiring Soon & Expired Tabs:** Filter subscriptions by days left (1-3 days, 4-7 days, 8-10 days) and take immediate action.
* **🔄 Interactive Modals:** Built-in popups for **Renew Subscription** and **Send Reminder** with quick message templates.
* **⚙️ Settings:** Account profile management, password updates, and configurable reminder notifications.
